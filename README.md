# Purr 2048 🐱→🦁

A cat-themed [2048](https://en.wikipedia.org/wiki/2048_(video_game)). Merge matching cats and grow them from a tiny newborn kitten all the way up to a **majestic lion (2048)**.

Swipe or use the arrow keys. Equal cats merge — and every merge gives a little **meow**. 🔊

Each tile value maps to its own cat photo, ramping in size: newborn → kitten → house cat → chonk → lynx → leopard → tiger → **lion**.
